CloudEval CLI

Install the CloudEval CLI with checksum-verified GitHub Release binaries.

curl -fsSL https://cli.cloudeval.ai/install.sh | bash

After install, run cloudeval login and cloudeval chat.

MCP server for agents

Expose CloudEval to Codex, Claude Desktop, Cursor, and other MCP clients:

cloudeval mcp serve

Focused toolsets are available for safer agent access:

cloudeval mcp serve --toolset readonly
cloudeval mcp status --format json
cloudeval doctor --mcp --format json

Codex CLI setup:

cloudeval mcp setup codex --dry-run
codex mcp add cloudeval -- cloudeval mcp serve
codex mcp list
  • Tools: ask, projects.list, reports.run, reports.download, billing.usage, and open.url.
  • Resources: cloudeval://capabilities, cloudeval://projects, cloudeval://billing/summary, and cloudeval://reports/latest.
  • Prompts: cost-review, waf-triage, architecture-review, and billing-review.
  • Auth: use cloudeval login, CLOUDEVAL_API_KEY, or --machine.
  • Transport: stdio MCP JSON-RPC. Server diagnostics use stderr only.

Session search and resume

cloudeval sessions search "cost spike" --format json
cloudeval sessions rename <thread-id> "Production cost review"
cloudeval chat --resume "Production cost review"
cloudeval ask "Follow up" --thread <thread-id>
