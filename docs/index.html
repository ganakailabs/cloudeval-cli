CloudEval CLI

Agent-ready terminal and MCP tooling for CloudEval projects, reports, billing, chat, and one-shot asks.

curl -fsSL https://cli.cloudeval.ai/install.sh | bash

After install, run cloudeval login, cloudeval status, and cloudeval chat.

First commands

cloudeval ask "Summarize my cloud risk" --format json
cloudeval agent "Find cost and architecture risks" --format json
cloudeval projects list
cloudeval reports list
cloudeval capabilities --format json
cloudeval help agents

Ask and Agent modes

ask is optimized for direct one-shot answers. agent uses CloudEval Agent mode for deeper non-interactive planner/tool execution.

cloudeval ask Summarize this project --project <id> --format json
cloudeval agent Find cost and WAF risks --project <id> --format json
cloudeval chat --mode agent
cloudeval setup --mode agent --non-interactive

Quotes are optional for simple multi-word prompts; use them when the shell would otherwise interpret punctuation, leading dashes, newlines, or spacing.

For text, JSON, and markdown output, ask/agent progress is written to stderr. Use --progress none or --quiet to suppress it, or --format ndjson --progress ndjson to stream progress and answer events on stdout. If CloudEval completes without final answer content, the command exits non-zero with a clear error instead of returning an empty result.

Update

Check or install the latest published CLI release without reinstalling manually:

cloudeval update --check
cloudeval update --yes

The default update output is a readable summary. Use --format json, --format ndjson, or --format markdown for automation.

Sensitive output

The CLI redacts account IDs, session IDs, tenant IDs, and sensitive URL query parameters by default. Use --show-sensitive-ids only for trusted local workflows that require full identifiers.

cloudeval auth status
cloudeval auth status --show-sensitive-ids

MCP server for agents

Expose CloudEval to Codex, Claude Desktop, Cursor, and other MCP clients:

cloudeval mcp serve
cloudeval mcp serve --toolset readonly

Codex CLI setup:

codex mcp add cloudeval -- cloudeval mcp serve
codex mcp list

Claude Desktop and Cursor setup helpers:

cloudeval mcp setup claude --dry-run --toolset reports --format json
cloudeval mcp setup cursor --dry-run --toolset billing --format json

Generic MCP clients and Ollama-powered agent hosts can use a standard stdio config:

cloudeval mcp setup generic --dry-run --toolset readonly --format json
  • Tools: capabilities_get, projects_list, projects_get, projects_export_diagram, ask, reports_list, reports_run, reports_download, billing_summary, billing_usage, billing_ledger, and open_url.
  • Compatibility: legacy dotted tool calls still work as aliases, but MCP clients should use underscore names.
  • Auth: run cloudeval login or cloudeval login --headless before starting the MCP server. MCP clients reuse the stored CloudEval session.
  • Transport: newline-delimited stdio JSON-RPC for modern clients, with legacy Content-Length framing accepted. Protocol messages use stdout; server diagnostics use stderr.
